# 正式仓库地图说明

本文件说明静态地图。唯一的机器可读来源是 `docs/formal_environment/environment.json`，预览图为同目录的 `environment.png`。源 JSON 的 SHA-256 为 `2a03a4abfe281de6865f39399d870f5ba9931d2520a6829bdb01788d50ca22fc`。地图本身不规定 AGV 数、任务流、充电规则或训练参数；这些由场景配置定义。

## 坐标和格子

坐标采用 `(x, y)`，左上角为 `(0, 0)`，`x` 向右、`y` 向下。地图宽 50 格、高 28 格，总计 1,400 格。

| 类别 | 数量 | 说明 |
| --- | ---: | --- |
| 货架格 `X` | 504 | 每格为一个独立货架，不可直接通行 |
| 普通地面 `.` | 878 | 不含站点的可通行格 |
| 拣选站 `G` | 10 | 可通行的交付目标 |
| 充电站 `C` | 8 | 可通行的充电位置 |
| 非货架可通行格合计 | 896 | 878 + 10 + 8 |

## 货架和通道

中央存储区有 7 列、9 行货架块，共 63 块。每块占 4×2 格，包含 8 个独立货架。货架块左上角横坐标为 `[8, 13, 18, 23, 28, 33, 38]`，纵坐标为 `[1, 4, 7, 10, 13, 16, 19, 22, 25]`。块间横向和纵向通道均为单格宽。全宽横向通道位于 `y=0,3,6,9,12,15,18,21,24,27`；左右边缘通道和中央纵向单格通道连接这些横向通道。全部 896 个非货架格属于同一个连通分量。

## 站点坐标

拣选站位于两侧边界，左侧为 `(0,1)`、`(0,7)`、`(0,13)`、`(0,19)`、`(0,25)`；右侧为 `(49,1)`、`(49,7)`、`(49,13)`、`(49,19)`、`(49,25)`。

充电站左侧为 `(0,4)`、`(0,10)`、`(0,16)`、`(0,22)`；右侧为 `(49,4)`、`(49,10)`、`(49,16)`、`(49,22)`。站点均互不重叠，也不占用货架格。

## 动态使用边界

场景 `llm-mappo-formal-8ag-v1` 将上述 JSON 转换为 RWARE 布局，启用全部 10 个拣选站和 8 个充电站，训练和主评估均使用 8 台 AGV。布局连通只能说明静态可达，不能推出载货通行、拥堵、充电恢复或连续任务流在运行中一定成功；这些仍需按验证方案实测。
