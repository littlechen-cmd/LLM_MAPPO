## 阅读约定

- 坐标原点 `(0,0)` 位于左上角，`x` 向右增加，`y` 向下增加。
- `X` 表示货架格，不是不可穿越的静态墙；`.` 表示 highway，`G` 表示目标。
- 本报告的“瓶颈”只描述载货运输所遵循的 highway graph，不声称空载 AGV 被墙式结构限制。
- PNG 使用深灰表示货架、浅灰表示 highway、绿色表示目标。充电站不属于 ASCII glyph，故不在 PNG 中单独着色，其坐标在下文列出。

## 共同合同与静态检查

- 尺寸 `20 × 24`，与 canonical core 一致，包含 `144 X + 334 . + 2 G`；
