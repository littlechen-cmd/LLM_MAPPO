# G3-6 车队—负载压力协议修订审查

## 修订决定

G3-6 不再实现窄通道和中心瓶颈两个未见布局，改为在核心 `24×20` medium 地图、目标点和
8 个固定充电位不变的条件下进行 8-AGV 车队—负载联合压力评估。冻结值为：

- `n_agents=8`；
- `batch_interval=40`；
- `batch_size_range=[6,13]`；
- `request_queue_size=13`；
- `task_completion_target=80`；
- `max_steps=1000`。

## 合理性审查

- 通过：批量期望值从 6 增至 9.5，接近车队规模 `8/5` 倍；目标任务数从 50 增至 80，
  保持每台 AGV 的任务尺度。
- 通过：地图、货架、目标点、充电位、能源、奖励、动作 mask 和规则安全层不变，压力来源
  限定为固定基础设施下的车队规模与任务负载联合增加。
- 通过：MAPPO 共享 actor 和注意力池化 critic 在结构上允许可变 agent 维度，但仍需实现
  checkpoint/shape/确定性 smoke。
- 有条件通过：QMIX mixer 固定为 5-agent 结构，8-AGV evaluation 只能使用共享 agent Q
  网络进行分散执行；必须证明 mixer 未加载、未调用、未更新，且新旧 5-AGV evaluator
  逐动作一致。
- 通过：保留正式 held-out seed、每 seed episode 数、final checkpoint 和统计单位不变。

## 证据收缩

本修订主动放弃未见拓扑零样本泛化证据。结果仅可支持：

- 固定仓库基础设施下的车队—负载联合压力鲁棒性；
- 更高交通密度下的吞吐保持、安全退化、充电竞争和规划成本变化。

结果不得支持：

- 未见布局或跨拓扑泛化；
- AGV 数量的独立因果效应；
- 任务到达强度的独立因果效应；
- 纯通道阻塞归因；
- QMIX mixer 的可变车队迁移能力。

## 一致性结论

`CONSTITUTION.md`、`TASKS.md`、G3 架构任务包、实验协议、方法—实验矩阵和 manifest 必须
以本修订为准。旧布局草稿与静态预览代码不再属于 G3-6，且不得混入后续 G3-6 实现 commit；
由于当前工作区已有未提交修改，本次修订不授权删除这些文件。
