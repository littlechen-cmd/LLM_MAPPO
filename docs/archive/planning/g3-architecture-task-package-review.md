- 通过：总任务包记录了角色权限、全局 seed/预算/指标合同、两阶段冻结、分任务证据、
  一致性矩阵、禁止事项、工程师启动指令和交接格式。

  固定出库点/充电位、静态距离边界、拓扑覆盖、防 checkpoint 选图、manifest 和测试要求。
- 通过：工程师只获授权修改布局、注册/透传、配置、manifest、审计、测试和 CHANGELOG；
  Constitution/TASKS 与长实验仍在其权限之外。

## 质量审查

- 通过：G3-P/G3-F 消除了正式预算依赖 G4-4 所造成的阶段顺序歧义，同时没有允许基于结果
  修改单组协议。
- 通过：未见布局主要改变拓扑，同时匹配网格、货架、任务、能源和接口，降低了面积、容量
  与负载等无关混杂。
- 通过：窄通道的双车让行与中央瓶颈的多方向汇聚具有不同诊断目标，不是两张同质“更难”
  地图。
- 通过：论文主张被限定为布局自适应 A* waypoint 支持下的零样本策略迁移，没有夸大为
  MAPPO 独立地图规划或摆脱执行期 A*。
- 通过：本任务未产生或引用算法性能结果，未把架构约束描述为已验证效果。

  不能自行放宽。
