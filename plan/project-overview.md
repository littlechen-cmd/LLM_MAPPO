## 研究背景

多智能体路径规划与调度既需要低层路径安全和冲突协调，也需要理解任务优先级、
电量风险和局部让行等高层语义。项目采用 A* 路径教师和离线 LLM 语义教师共同
监督 MAPPO，以研究异构教师知识能否形成互补，并减少执行期对在线 LLM 的依赖。

## 研究目的

构建并验证一套双教师知识蒸馏方法：A* 提供路径偏好，离线 LLM 提供任务投入度
与局部通行倾向，MAPPO 学习多智能体动作策略。当前方法保证执行期零在线 LLM
调用，但仍使用 A* 生成 waypoint；摆脱执行期 A* 属于后续优化方向。

## 研究方法

- 在统一动态仓储环境中进行四组核心因子对照。
- 以相同环境交互步数作为主要训练预算。
- 每组至少使用 5 个独立训练 seed。
- 使用未见 seed、不同负载和不同规模进行评估。
- 报告均值、标准差、95% 置信区间、显著性和效应量。
- 对不同 LLM 教师先进行标签质量与成本比较，再决定是否扩展训练。
