# 语义合同 v3：三维主语义与第四辅助维度

日期：2026-10-08。
状态：研究所有者已批准前三维的含义与命名，并要求第四辅助维度；第四维按本次
命名为 `motion-stagnation`。所有者已确认前三维由 LLM 标注、第四维由同一可观察窗口
规则派生；数值锚点、质量门和 loss 权重仍须冻结。
本合同取代此前两维建议及三维候选中的临时字段名，不改变历史标签的语义身份。

## 字段及固定顺序

| 顺序 | Canonical 字段 | 中文含义 | 角色 | 标签来源 |
| --- | --- | --- | --- | --- |
| 1 | `goal-priority` | 自身当前目标的内在优先性 | 主语义 | LLM |
| 2 | `yielding-preference` | 局部交互中自身让行的适宜性 | 主语义 | LLM |
| 3 | `local-constraint` | 可见范围内的局部结构性机动约束 | 主语义 | LLM |
| 4 | `motion-stagnation` | 可观察的持续受阻或重复振荡 | 辅助维度 | 同窗口规则派生 |

JSON 标签键、配置维度列表、manifest 和导出身份使用上表带连字符的精确名称。
Python 标识符必要时可用下划线，但字段映射必须明确，不能更改 canonical 名称。
“辅助”表示需单独报告并配置 loss 权重，不代表已批准某个数值权重，也不表示可以
把该维度仅留作 metadata 而完全省略预训练辅助目标。

## 1. goal-priority

基于当前 self/goal 的 phase、有效 priority、电量与载货上下文，评价自身目标的
内在优先性。不能因邻车多、通道窄或 blocked 次数多而直接抬分。
不得推断 deadline、剩余航程、全局收益或下步必须前进；充电硬约束始终优先。
不同阶段的明确评分锚点随后冻结。

## 2. yielding-preference

在局部交互证据成立时，结合双方可观察的相对优先性、phase、电量和空间关系，
评价由自身让行的语义适宜性。不得把“有邻车/有拥堵”直接等同为高让行偏好。
不判断邻车的隐藏目标与规划路径，不输出具体动作、先后通行分配或全局最优顺序。
同级对称、交互对象或关键属性不足时记录 unknown/mask；无局部交互证据的零分
只表示没有已见让行依据，不表示自身取得先行权。

## 3. local-constraint

依据当前 5×5 cells 与自身载货状态描述可见结构性机动限制；不以 priority、
邻车数量或受阻历史直接代替地形证据。空载可进入货架格；载货时结合实际货架
占用规则判断，不把另一台车携带的货架武断视为静态墙。
充电/拣选服务锁不属于局部地形限制；可见范围以外的连通性保持未知。
本维度不宣称全局瓶颈或目标全局可达。

## 4. motion-stagnation

两个英文单词分别表示运动与停滞，中文工作名为“可观察运动停滞”。
它只描述 8 帧窗口内有直接证据支持的持续受阻或重复振荡，不能写成已确认死锁、
全局死锁或任务失败概率。

允许的主要证据为原始动作、previous_blocked、朝向及同一有效阶段内的时序结构。
单次转向、单次受阻、距离暂时不下降或 NOOP 本身均不足以支持高分。
goal type/phase 一致不证明目标身份一致，距离趋势不能单独证明停滞。

合理充电或拣选服务停留不作为正例；仅凭当前 observation 无法区分的停留保留未知。
当前已到充电目标、局部中心是 charger、尚未满电的状态，应按已冻结充电合同处理，
不能因旧窗口中曾转向或 blocked 而把当前正常充电服务标成运动停滞。
死亡/idle 不直接作为停滞正例，窗口阶段边界之前的动作不归因于新阶段。

该维度可以与 local-constraint 相关，但不是其复制：狭窄通道中顺利行驶可高约束、
低停滞；宽敞空间中重复左右振荡可低约束、高停滞。

## 版本与剩余冻结工作

- 四维的排序与含义和旧 `mission_urgency/concession_appropriateness/
  interaction_risk/deadlock_severity` 不同，不能直接重命名或迁移旧 semantic head。
- Actor 的 209D 输入和 encoder/GRU 接口保持现有范围；新 head、训练配置及表征
  身份必须绑定新合同。旧产物独立保留。
- LLM 响应只要求前三个字段；第四维由相同可观察窗口的冻结规则独立计算，
  合并为四维训练目标时保留分维来源、证据、规则版本和 mask，不能称为四维 LLM 输出。
  LLM prompt 不注入第四维规则分数，也不要求 LLM 复述规则结果。
- 具体锚点、unknown/mask 条件、试标/复标/对照数量、覆盖和重复度质量门、
  auxiliary loss 权重，在下一个冻结任务中提交并审阅。

完整输入审查及可区分场景见
[可观察性分析](semantic-dimensions-v3-analysis.md)。
