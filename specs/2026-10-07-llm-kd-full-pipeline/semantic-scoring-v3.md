# v3 评分、试标与预训练合同

日期：2026-10-08。状态：所有者已批准，按本日修改允许前三维连续评分。
字段含义与来源遵守 [语义合同 v3](semantic-contract-v3.md)。
本合同将执行规则具体化，不重开已经确认的维度、数据量或正式训练 seeds。

## 1. 通用格式和证据

LLM 仅返回前三维，已知分数允许 `[0,1]` 内任意有限连续数值；未知返回 JSON null。
`0/0.25/0.5/0.75/1` 及下文表格仅提供语义参考锚点，不是输出枚举或量化规则。
例如有对应可观察证据的 0.37、0.63、0.82 均可保留。解析、缓存、检查、打包及训练
不得四舍五入到锚点，也不得以“不等于参考值”拒绝标签；语义证据及 unknown 条件
继续检查。规则 comparator 可输出离散参考值，不能作为 LLM 分数必须精确匹配的真值。
第四维仍由冻结规则生成确定数值，不受此次连续输出修改影响。
每维提供 1–4 个真实原始观测路径。unknown 附带固定 reason code，不自由描述动作。
已知值不能附 unknown reason；null 不能转成有效零分。
上述证据数量限制适用于 LLM 前三维；第四维规则保留完整重算所需的全部原始路径，
不为满足 4 条上限而删去连续动作、blocked 或距离证据。

unknown reason 仅允许 `ambiguous-peer-association`、`missing-peer-attributes`、
`symmetric-priority`、`conflicting-peer-evidence`、`hard-service-lock`、
`ambiguous-service-state`、`ambiguous-shelf-mobility`。前六项适用于 yielding；
最后一项适用于 local-constraint；motion-stagnation 仅允许服务状态不明确的原因。
goal-priority 的必需字段损坏属于输入失败，不以 unknown 掩盖。
证据可以引用原始标量或原始 cells 列表；不得引用模型自造解释或第四维规则分数。

合并训练记录包含四维 scores、四维 known_masks、每维来源及证据：前三维来源
`llm`，第四维 `observable-rule-v3`。数值张量可将 null 存成 0 占位，但对应 mask
必须为 false，原始标签仍保留 null。禁止把低置信分数当 unknown 的替代品。
raw observation、semantic view 和分维标签均绑定哈希。

## 2. goal-priority 锚点

评价当前目标的内在优先性，采用下列明确锚点。不以邻车、窄通道、受阻或载货本身加分。

| 当前可观察条件 | 分数 |
| --- | ---: |
| idle 或电量为 0，没有可执行的活跃目标 | 0 |
| 活跃的非充电目标，没有有效任务 priority，例如回收/归位目标 | 0.25 |
| 非充电任务 priority_weight=0.5 / 0.75 / 1.0 | 0.5 / 0.75 / 1.0 |
| charging，电量至少 0.30 且小于 1.0 | 0.25 |
| charging，0.15≤电量<0.30 | 0.5 |
| charging，0.05<电量<0.15 | 0.75 |
| charging，0<电量≤0.05 | 1.0 |

phase 与 goal type 不一致、出现本合同没有定义的有效 priority 或输入无效时，不猜分；
视为配置/数据问题停止处理。满电仍长期处于 charging 应报环境合同异常。
以上是项目的优先性语义约定，不宣称可由电量得知剩余路径或能量死亡概率。
充电触发阈值建议沿用当前 medium 的 0.30；其他环境冻结时保持同一阈值。

该维度已有强规则 comparator；仍保留 LLM 标签，以检验模型是否遵守上下文语义。
不得把复述锚点称为超越规则的推理能力。

## 3. yielding-preference 锚点

先区分三个状态，不能把它们全部标成零分：

1. 当前没有局部竞争证据：已知 0，表示没有已见让行依据。
2. 存在局部竞争且双方属性/相对关系可确定：按下面锚点评分。
3. 有竞争但对象关联不清、属性不足、同级对称或服务状态不确定：null，mask=false。

局部竞争必须引用当前占用及关系证据。例如前方格被近邻占用并有当前受阻 forward，
或相邻/同一可见通道内存在朝向与最近动作支持的相向接近；仅有远端有效 peer 或
附近任意 AGV 不足以判定竞争。不能从朝向单独推断未来目标/路线。
对相向接近只描述当前可见交互趋势，不赋予真实碰撞概率。

执行时直接竞争限定为：当前前方相邻格由已关联近邻占用，且自身上一动作是受阻
FORWARD。弱交互限定为：双方当前同一局部直通道、间隔两格、相向，最近动作均为
未受阻 FORWARD，中间格结构可通行且无其他 AGV。朝向转换只用当前自身及 peer
朝向，不将当前 peer 槽当作历史同一对象。其他局部占用关系没有足够证据支持强弱
判定时记 unknown，不凭自由解释补分。无局部 AGV，或观察明确不满足上述关系时
给已知 0，仅表示本合同未见竞争依据。

将双方的可观察目标优先性按第 2 节同一约定评价；近邻无 goal geometry，不尝试
推断它的目标位置。以相对优先性差作为锚点，不把自身 A 的高低直接复制到 B。

| 可观察竞争关系 | 分数 |
| --- | ---: |
| 自身优先性明确高于已关联的竞争近邻 | 0 |
| 较弱但具体的局部交互迹象，近邻优先性更高，尚无直接占位阻挡 | 0.25 |
| 直接竞争，近邻优先性高 0.25 | 0.5 |
| 直接竞争，近邻优先性高 0.5 | 0.75 |
| 直接竞争，近邻优先性高至少 0.75 | 1.0 |
| 同级对称、冲突对象不明确、多个相关近邻给出相反且无法消解的依据 | null |

本维度评价相对让行依据，不发出动作，也不判断具体退让位置是否安全。
当前已进入硬充电服务时，本维度用 null/`hard-service-lock`；规则层决定停留，
不能把服务中不能移动误写成模型建议让行。
判定顺序为硬服务锁、关系与对象可识别性、双方优先性比较、竞争强度；弱交互也必须
先比较优先性，自身更高为 0、同级为 null。不能仅因弱交互而固定给 0.25。

明确硬充电服务的可观察条件为 charging phase/type、goal 三个几何量绝对值均不大于
1e-6、中心格 charger=true，且 0<battery<1。中心格为 workstation、目标几何量
为零且 phase 为 task/delivery 时，未显式观测拣选服务锁；若服务是否成立会改变
让行判断则用 `ambiguous-service-state`，不从 NOOP 自行推断服务倒计时。

### 当前 peer 与局部格的对应

不跨帧假定 peer ID。需要具体对象时，只做当前帧的可验证对应，失败则 unknown。
局部图半径 2，图内最大 Euclidean 距离为 √8；图外最小格距为 3。因此只要图内有
其他 AGV，最近有效 peer 一定位于图内。

可由局部占用格的最小距离与 peer_0 的归一化距离恢复当前坐标比例，随后把当前
peer 的相对坐标还原并核对整数格、占用及距离排序。残差容差建议 1e-4 格。
推导只使用当前 observation，不读取真实 Agent ID、全局坐标或环境私有状态。
映射不唯一、不一致、有效槽缺失或浮点残差超限时，不强行对应。
新增派生映射仅帮助定位，标签仍引用其原始 peer/cells 证据。

## 4. local-constraint 锚点

忽略其他 AGV 的临时占用，评价结构性机动空间。使用原始 cells 和 carrying，
不能直接采用旧摘要 non_peer_free_degree，因为它把货架一律计为阻挡。

- 越界/静态障碍为确定不可进入；站点通道本身不是墙。
- 空载：货架不构成结构性阻挡。
- 载货：无其他 AGV 同格的站立货架构成阻挡。
- shelf 与 other_agv 同格：可能是移动货架；对结构性可进入性保留不确定。
  若这种不确定会改变评分等级，返回 null/`ambiguous-shelf-mobility`。

记 d 为当前中心格四个相邻格中的结构性可进入数量。

| 可见结构 | 分数 |
| --- | ---: |
| d=4，四向均有局部结构性入口 | 0 |
| d=3，有三个入口 | 0.25 |
| d=2，转角或相邻两步内可见分支/开阔空间 | 0.5 |
| d=2，两个入口相对，近邻两步内可见连续窄通道、无分支 | 0.75 |
| d≤1，当前可见空间仅有一个或没有结构性出口 | 1.0 |

“两步内可见分支”指局部图上由中心出发、最多两条四邻接边可达的格子存在至少
三个结构性邻接入口；图外入口不计作已知分支，也不当成墙以推断全局死路。
必须引用支撑分类的格子；不能称全局无法通行。原地转向不要求货架转弯半径，
因此不能凭车辆朝向额外发明动力学约束。

## 5. motion-stagnation 规则

同一 8 帧窗口的规则辅助目标，始终与 LLM 三维标签分开生成和记录来源。

取窗口末尾同一 phase、同一 goal type 的连续段；忽略该段第一帧携带的上一动作，
它可能属于此前阶段。距离变化不能证明目标身份不变，只作振荡排除检查。

- **连续受阻证据：**末尾至少 3 个连续动作均为 FORWARD 且 blocked=true；
  B 为这个连续尾段长度。中途 NOOP、转向或未受阻前进均中断连续段，不能把散落
  在窗口中的受阻次数相加后称为连续受阻。
- **重复振荡证据：**末尾连续转向段至少 4 次 LEFT/RIGHT，至少 3 次方向交替；
  从该段第一动作之前一帧到当前帧，goal distance 极差≤1e-6；
  A 为这个连续转向尾段的交替次数。其他动作中断此模式。
- idle、电量为 0、当前合理充电服务，以及当前可观察停留无法排除拣选服务时，
  不产生正分。明确充电服务给 0；服务是否成立无法确定且会改变结论时给 null。
  服务位置的可观察判据沿用第 3 节；当前处于上述 workstation/零距离条件且
  原本满足正分模式时，以 null 保留拣选服务不确定性，否则按模式缺失给 0。
- 不具备上述证据时给 0；只表示当前观察窗口没有满足该代理，不证明没有死锁。

| 模式强度 | 分数 |
| --- | ---: |
| 满足受阻模式，B=3 / 4 / 5 / 至少 6 | 0.25 / 0.5 / 0.75 / 1.0 |
| 满足振荡模式，A=3 / 4 / 5 / 至少 6 | 0.25 / 0.5 / 0.75 / 1.0 |

两种模式同时满足取较大值。该阈值是冻结的可观察代理，不与全局 deadlock detector
混用。规则生成、重算及 evidence 一致性必须为 100%。

## 6. 最少试标与质量门

每环境从已冻结 train 选样中确定 120 条试标，合格标签计入正式主集。前三维主模型
Flash，前述版本化 prompt；同一固定 40 条分别复标与 Pro 对照。60 条分层匿名审阅
由 Codex 执行并如实标明身份。新语义数据不足以通过时停止，不追加无目标 smoke。
前三维首次真实请求即首条试标；第四维不发送 API 请求。

| 项目 | 建议门槛 |
| --- | --- |
| 首次 JSON/类型解析率 | 至少 98% |
| 常规重试率 | 至多 10%，每条最多 1 次常规重试 |
| 动作/路径/任务分配等禁用内容 | 0 |
| 已接收标签的引用路径及数值范围 | 100% 合法 |
| 三维 LLM 有效标签总体标准差 | 每维至少 0.08；mask=false 不参与计算 |
| 同模型复标配对 MAE | 每个 LLM 主维至多 0.15 |
| Pro 对照配对 MAE | 每个 LLM 主维至多 0.20 |
| known/unknown 状态一致率 | 每维至少 90%，每维共同已知配对至少 20 条 |
| 60 条审阅 | critical=0，substantive≤3；普通场景、竞争、结构及服务均覆盖 |
| 第四维规则重算及引用 | 100% 一致，不套用 LLM 复标指标 |

未知比例单列：建议 train 各主维已知率至少 60%；validation/test 每主维已知样本
至少 max(20, ceil(分区样本数×20%))。不通过时审查可观察性与采样，不能填造分数。

### 覆盖与重复度

- train 中每主维至少 5% 的总窗口数有已知分数≥0.5，至少 10% 有已知分数≤0.25。
  tiny/medium/formal 的正分下限分别为 35/105/280 条。
- yielding 另要求至少 5% train 有真实竞争且自身优先性更高的已知低分，不能全部
  用“无邻车”零分完成反例覆盖。
- 第四辅助维 train 的已知正分（≥0.25）至少 max(10, ceil(train 数×1%)) 条，
  即 10/21/56 条，并至少 10% 为已知零分；避免辅助目标退化为全零。若自然轨迹
  不足，报告覆盖缺口并暂停冻结，不通过扩大“停滞”定义凑数。
- 充电服务覆盖 train 至少 min(30, ceil(train 数×2%)) 条，即 14/30/30 条；
  结构受限但不停滞、空间开阔但停滞等实际可得反例分别记录，不伪造环境状态。
- 边界率为诊断项，不因合理零分多而自动失败。
- 对三个主维，排除两维同时为零的样本后，同分率≥95% 或 |Pearson r|≥0.95
  触发语义重复审查并暂停批量；剩余共同已知样本少于 30 或任一维为常量时报告不可估计，
  不能记作零相关。按任务阶段、载货和竞争分层报告，不能只看总体相关。
- 审查不强迫统计独立，不人工改分或删样本降低相关。数值门失败必须留下结果。

正式窗口在标注前按原始状态冻结；以上输出覆盖检查不能用于偷偷筛选“好标签”。
需要调整采样/锚点时另建版本并审批，不覆盖失败试标。

## 7. Pretrain 权重与选择

建议固定权重：`[1.0, 1.0, 1.0, 0.25]`，顺序遵循 canonical 四字段。
不做权重搜索。仅监督窗口末帧，前七帧是 GRU 上下文，不复制末帧标签。

每维先按该维 known mask 计算有效样本 MSE，再加权平均：

`L = sum_d(w_d * mean_valid_d_squared_error) / sum_d(w_d)`。

无已知标签的维度不参与当前 batch 的分子和分母；整个 batch 都无有效目标时
跳过更新并记录计数。unknown 不贡献梯度，也不因某维未知多而隐式降低该维固定权重。
validation 按全分区逐维误差总和/有效计数聚合，不能平均不同大小 batch 的平均值。

建议 pretrain seed=7、batch=256、Adam lr=0.001、max_epochs=100、
patience=10、min_delta=0.0001；不另跑调参 smoke。新语义头从随机初始化训练。
用 validation 实际最小 loss 选 best；min_delta 只控制耐心，不把略优但不足
min_delta 的模型排除出数学意义上的最佳。test 在配置冻结后一次性报告。

## 8. 已批准的冻结范围

所有者批准本合同并将前三维改为连续评分，冻结 unknown 规则、采样质量门、试标数量、辅助权重、基础
pretrain 超参数，以及 medium 的充电触发阈值 0.30。它不等于批准新的外发载荷，
也不替代 formal 容量管理、tiny/formal 环境完整配置和正式 RL 评价协议的独立冻结。
实现首次真实试标前，仍应提供实际冻结窗口、prompt、模型身份和费用预留凭据。
