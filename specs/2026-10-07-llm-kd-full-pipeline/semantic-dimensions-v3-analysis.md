# 至少三维语义的可观察性与区分度分析

日期：2026-10-08。状态：分析建议，三维具体定义与质量门尚未冻结。
研究所有者要求至少三维，已批准 medium 新建 3,000 条。此前两维建议停止采用。
本轮不调用 API，不改动旧标签，也不把候选定义标为已获批合同。

本轮后续批准：所有者采用三维含义，并指定名称为 `goal-priority`、
`yielding-preference`、`local-constraint`；增加 `motion-stagnation` 第四辅助维度。
当前冻结的命名及边界以 [语义合同 v3](semantic-contract-v3.md) 为准，
下文的下划线名称保留为分析历史，数值质量门尚未批准。

## 1. 当前 LLM 实际输入

核对 `temporal_view.py`、`structured_observation.py` 与 `medium_prompt.py` 后，
当前输入为 Actor 原始 209D 观测构成的 8 帧序列，经确定性转换得到：

| 信息组 | 可用字段 |
| --- | --- |
| 自身 | 朝向、载货、电量、task phase、priority weight、上一动作、上一 forward 是否受阻 |
| 自身目标 | goal type、自身坐标系下归一化方向分量与 Euclidean distance |
| 局部地图 | 自身坐标系下 5×5，越界/静态障碍、货架、拣选站、充电站、其他 AGV |
| 邻车 | 最近至多 3 个匿名槽位，位置分量、朝向、载货、电量、phase、priority、上一动作及受阻标志 |
| 时序摘要 | 动作计数、受阻计数、转向计数、NOOP 连续数、阶段年龄下界、距离趋势和局部邻车统计 |

summary 是同一批观测的派生量，不新增可知信息。formal 的局部图可能包含多于三个
邻车，但只有最近三个带详细属性；tiny 的第三槽可无效，不能把填充值当真实邻车。

### 不能使用的信息

邻车目标/计划路径、稳定邻车 ID、稳定目标 ID、全图拓扑、实际剩余路径长度、任务
deadline、任务已等待时间、全局队列状态、充电 reservation/FIFO、显式 picking lock、
显式充电锁或执行 mask，均不在当前 LLM view 中。

`anonymous_nearest_peer_distance.peer_identity_available=false`，相邻帧同一槽位
不能假定是同一台车；`goal_distance_trend.target_identity_available=false`，
同一 phase/goal type 也不能保证是同一个目标。转向会改变自身坐标系，不能直接用
相邻帧的相对坐标差计算邻车世界速度。

邻车位置按地图对角线归一化，局部 cell offset 是整数格，当前 view 没有显式比例尺
或 peer-to-cell 映射；不得凭近似数值把某个 peer 的优先级强行绑定到某个占用格。
方向符号、近邻排序和独立的局部占用证据可用，精确对应不确定时需保留未知。

## 2. 推荐三维

### 维度 A：自身目标优先性 `goal_priority_pressure`

通俗解释：先不考虑谁挡住谁，这台车当前目标本身有多强的优先需求。

专业定义：基于当前 phase、有效任务 priority、载货及电量，对自身当前目标的内在
优先性进行有界语义评价。高分表示目标优先性强，不表示下步必须前进。

主要证据为当前 self/goal，不用邻车数量、局部窄度或受阻次数直接抬高分数。
高优先任务与低电量补能都可能形成强需求，二者的相对锚点需由项目合同明确。
同优先级任务不能仅因载货就一律标高分；phase/载货的影响需有固定锚点。
不能推断即将逾期、完成概率、到站前必然耗尽电量或全局收益最大化。
充电锁定中的低电量仍可有补能优先性，该值不是解除硬约束的指令。

### 维度 B：局部让行依据 `local_yielding_appropriateness`

通俗解释：当前可见局部竞争中，有多少证据支持由自己让出通行优先性。

专业定义：在有局部交互证据的前提下，评价自身相对可见近邻的让行适宜性。
依据相对任务优先性、phase、电量与当前可见空间关系；不预测邻车路线。

必须同时引用局部交互证据与双方的可观察属性。邻车出现、拥堵或高风险不单独构成
高让行分。高优先自身与低优先近邻、低优先自身与高优先近邻应形成不同锚点。
无需也不能断言“谁先走必然更优”。同级对称、不能确定交互对象或缺少关键属性时
记录 unknown/mask，不给任意 0.5。无局部交互证据可给 0，但含义仅为“没有已见
让行依据”，不是宣称自身具有先行权。

本维度不评价具体后退动作是否安全或存在可达避让点；机动空间由维度 C 独立描述。
不能为了避免与 A 相关而人为打乱分数；相对让行确实可能随自身优先性降低而升高。

### 维度 C：可见局部机动约束 `local_maneuver_constraint`

通俗解释：只看当前能看到的地形和载货条件，局部可用的移动空间有多受限。

专业定义：结合自身载货状态与 5×5 局部地图，评价可见范围内的结构性机动受限程度。
这是当前快照的局部结构语义，不是全局瓶颈、最短路径可达性或未来通行能力。

可引用相邻格、局部连通空间、分支和可见侧向空间。只在可见范围判断，边界之外
视为未知。priority、邻车数量及受阻历史不能直接抬高该维度。

必须遵守实际 movement 规则：空载可进入货架格；载货车不能进入无 AGV 占用的
站立货架格。货架与其他 AGV 同格时，不能仅用 shelf 通道认定为静态障碍，
可能是另一台车携带的货架。拣选站/充电站本身不当作墙，充电服务锁也不是地形受限。
所以旧 `non_peer_free_degree` 把 shelf 一律当阻挡的摘要只能作几何提示，
不能直接当本维度真值；需回到 cells 和 self.carrying 判断。

本维度可由规则产生强 comparator；LLM 是否能提供额外价值需比较，不预先保证。
即使最终规则已足够，它也可以是有用的辅助表征目标，但不能据此宣称 LLM 独有推理。

## 3. 为什么三维可区分

| 可观察场景 | A 自身优先性 | B 让行依据 | C 局部约束 |
| --- | --- | --- | --- |
| 高优先任务，宽敞、无局部邻车 | 高 | 低 | 低 |
| 低优先任务，宽敞，但当前有更高优先近邻竞争 | 低 | 高（证据足够时） | 低 |
| 高优先载货任务，狭窄通道，独自行驶 | 高 | 低 | 高 |
| 低优先载货任务，狭窄通道，无局部邻车 | 低 | 低 | 高 |
| 高优先自身遇到同样更紧急的近邻，宽敞局部 | 高 | 可高 | 低 |
| 相同局部地图由空载变为载货，优先性不变且无邻车 | 不因空间变化抬高 | 低 | 可改变 |

表中是定义反例，不是新造的正式数据或模型实测。它们证明不存在必然的同分关系，
不能证明实际 dataset 中的三个分数统计独立。

## 4. 其他候选及取舍

| 候选 | 当前输入支持程度 | 建议 |
| --- | --- | --- |
| 可观察连续受阻/振荡 | 支持直接动作与 blocked 证据；不证明全局死锁 | 保留规则诊断；必要时作为第四辅助维，而非强行叫 deadlock |
| 局部交互强度 | 可描述当前占用和朝向，不能预测真实碰撞概率 | 备选第四维；防止再次与 B 共用“有邻车即正分”的定义 |
| 能量紧迫程度 | 当前电量/phase 可用；不能可靠预测剩余航程 | 可替代 A 的一部分，但单列易退化为电量阈值复制 |
| 任务推进效率 | 无稳定目标 ID，距离为 Euclidean，服务停留可能合理 | 不作为默认标签 |
| 全局死锁/最优通行顺序/任务逾期风险 | 缺少关键输入 | 排除 |

## 5. 在正式生成前验证区分度

1. 固定维度的证据边界、正负锚点与 unknown 条件，不能全部共用同一段“0/0.25/0.5”解释。
2. 从真实 train 候选中选择上述可区分场景；未找到的组合记为覆盖缺口，不伪造轨迹。
3. 首批试标计入新 medium 的 3,000 条；分别检查每维证据正确性、分数层次及 mask 比例。
4. 同时报总体和交互/任务/载货分层的相关、同分率及条件分歧；不能靠大量共同零分判重复。
5. 对 A/B 固定自身状态比较近邻属性变化，对 A/C 固定优先性比较局部结构变化，
   对 B/C 固定相对优先关系比较宽窄空间。使用真实可比样本；没有可比样本不作因果主张。
6. 高相关是审查信号，不能通过删样本、人工改分或强迫反相关满足阈值。
   具体数值门随锚点合同提交所有者批准。语义错误或持续重复即停止批量调用。

可以在 prompt/schema 和检查器层面禁止越界推断；统计不重合与 RL 效果必须由试标
和正式实验验证。至少三维的数量底线已冻结，第三维不以尚不可观察的事实填充。
