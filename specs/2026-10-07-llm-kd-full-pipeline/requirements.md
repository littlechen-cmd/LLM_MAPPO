## 整体方法

1. 冻结环境与安全约束，准备对应环境的行为 Actor。
2. 采集连续可观察轨迹；先按 episode 切分，再选取时序窗口。
3. 训练分区覆盖协调困难场景和普通对照；held-out 分区不按模型分数挑选。
4. 离线 LLM 生成语义标签，通过证据、覆盖、一致性与审阅质量门。
5. 从观测序列预测窗口末帧语义，预训练 encoder、GRU 和 semantic head。
6. 使用 validation 选择最优 pretrain checkpoint，仅导出 encoder/GRU。
7. 将表征分别导入 MAPPO 和 A* KD 的 Actor，再进行正式 RL 训练。
8. 使用冻结的 final RL checkpoint、held-out seeds 和配对统计评估。

执行期间在线 LLM 调用为零。LLM 不分配任务或发出逐步动作；A* 保持当前训练教师边界。
充电停留来自规则层，不能计为 LLM 学会充电。pretrain 的 best checkpoint 与正式
RL 的 final checkpoint 是不同阶段的选择规则，不能混用。

## 环境与充电合同

- 所有四组方法、数据采集和评估使用相同的充电服务规则。
- 到站锁定必须核对当前充电目标与实际站点；普通经过充电站不能误触发锁定。
- 锁定期间统一合法动作与实际执行动作，持续获得充电增量，到 100% 后解除。
  PPO 存储的 action mask、log probability 和执行动作必须一致。
- 充电速率固定为 `0.1/步`，其中“步”指仿真环境 step，不是 PPO update 或累计
  worker transitions。电量按 `min(1.0, battery + 0.1)` 增加，禁止超过 100%。
  该参数纳入三环境共同配置及 manifest 身份；不沿用旧数据的充电速率声明。
- 原先 80% 释放的参数不能继续影响新合同；充电触发阈值在环境冻结时明确。
- 充电中的合理停留不判为无进展死锁，采样及语义输入必须能区分服务停留和阻塞。
- formal 保持 50×28 地图、8 个充电站；2026-10-08 所有者明确 AGV 数后续提供，
  当前不冻结规模或开展其容量决策，不把旧 8/12 AGV 方案当作执行配置。
- formal 规模确定后，再核对 runner、站点数量、目标分配、容量不足、占用释放与
  失败处理是否兼容；必要的容量合同届时提交批准。不能自行增加站点或伪造目标。
- tiny/formal 的完整配置、负载、训练步数尚未冻结；任务组 1 必须完成冻结，之后
  才能生成对应正式数据。medium 也必须记录新充电合同及配置哈希。

## Pretrain 与接入

- 修复当前导出停止时模型而非 validation 最优模型的问题。
- test 不参与超参数、语义定义或 checkpoint 选择；最终一次性报告分维误差与分层误差。
- 报告与简单常量预测、同窗口规则标签对照的关系，避免仅用总体 loss 掩盖稀少正例。
- 表征导出绑定观测、语义、数据、配置、代码及权重哈希，验证导入权重相等。
- action head 与 Critic 不从语义 pretrain 导入；各方法保持相同初始化策略和匹配 seeds。
- 每环境 pretrain 固定 seed 7，导出的同一表征用于该环境全部八个 RL seeds。
  八个 RL seeds 估计固定表征条件下的 RL 波动，不构成 pretrain 随机性鲁棒证据。
- 当前 provisional pretrain YAML 不自动变为 approved。其余超参数及规则对照的
  运行范围在任务组 3 冻结；不执行无目标的大规模搜索。
- 支持中断恢复，保留 best/latest 区别，拒绝混合不同数据或语义身份。
