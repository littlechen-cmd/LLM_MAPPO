# Mission

## 项目名称

LLM-A-MAPPO 多教师蒸馏多智能体路径规划与调度研究

## 一句话概述

面向动态仓储多 AGV 场景，构建以 MAPPO 为最终动作策略、A* 为路径/运动教师、离线 LLM
为双语义教师的多教师蒸馏系统，在执行期保持零在线 LLM 调用。

## 目标用户

- 多智能体强化学习与知识蒸馏研究者；
- 仓储机器人路径规划、运动协同与调度研究者；
- 评审本项目方法、实验与可复现证据的论文评审者。

动态仓储 AGV 是方法验证场景。当前项目交付目标是可复现的研究方法与论文证据，不是可直接
部署到真实仓库的商业调度产品。

## 要解决的问题

项目研究两类异构教师能否向同一 MAPPO 策略提供互补监督：A* 提供可解释的路径与局部运动
先验，离线 LLM 提供 `task_commitment` 和 `local_assertiveness` 双语义监督，MAPPO通过环境
交互、team reward 与集中式 critic 学习最终运动动作和多智能体协同。

当前项目同时面临创新风险与截止期限风险，因此采用双路线并行、正式实验单路线选择：

### 优化路线

- Git 分支：`codex/optimization`；
- 重新设计 A* 教师的算法和架构定位，经过人工批准后才允许实现和训练；
- 将 A* 限定为针对规则层既定目标的局部几何运动教师，不承担任务选择、优先级重排或充电
  意图决策；
- 建立窄通道与中央瓶颈/交叉通道两个真正的未见拓扑；
- 不实施同图 8-AGV 压力场景；
- 以形成具有中科院二区竞争力的方法与实验证据为现实目标。

### 稳定路线

- Git 分支：`codex/stable`；
- 兼容恢复旧 Phase 3 A* 行为，同时保留 A* 路径教师、离线 LLM 教师和 MAPPO；
- 最终验收环境固定为旧 Phase 3 合同：3 AGV、任务完成目标 9、动态入库；
- 能源与充电参数直接冻结为 `1.10/0.30/0.80`，引用既有测试证据，不再安排能源选择 pilot；
- 不建设未见拓扑，也不实施同图 8-AGV 压力场景；
- 只承诺保证项目按期形成完整、可复现的论文实验，不保证达到中科院二区竞争力，不支持
  跨拓扑泛化主张。

## 成功标准

### 共同标准

- 始终保留“A* 路径/运动教师 + 离线 LLM 双语义教师 + MAPPO”的多教师技术主线；
- MAPPO 是最终动作策略；规则层继续负责任务队列、合法目标、充电安全目标和硬约束；
- 训练、评估和执行阶段在线 LLM API 调用次数均为 0；
- 正式实验前冻结代码、环境、奖励、seed、训练预算、checkpoint 规则、指标和失败处理；
- 每项论文主张都能追溯到冻结日志、统计证据或明确限制。

### 优化路线进入正式实验的条件

- A* 教师重设计方案经过研究所有者人工批准；
- 实现通过确定性教师纯度、接口、安全、回归和短 smoke；
- 有效教师覆盖率不低于 25%；
- 教师标签中的目标改写、端到端协调器污染和非法动作概率质量均为 0；
- 三 seed 校准中，相对 `MAPPO-WP` 的标准化吞吐 AUC 中位数退化不超过 10%；
- 两个未见拓扑的文件、哈希、统一接口和防泄漏规则完成冻结。

### 稳定路线验收条件

在非正式验收 seed `300–309`、每 seed 20 episodes 下：

- 任务完成率不低于 95%；
- 碰撞率为 0；
- 能量死亡率为 0；
- 终止死锁率不高于 1%。

不要求精确复现历史 99.72% 完成率。若未通过，只允许修复已确认的旧行为恢复错误并按原合同
重跑；不得调整已冻结能源参数或按结果更换 seed。

## 正式路线选择

- 两条路线同步进行代码实现、短验证和实验准备；
- 正式评估 seed `200–209` 使用前必须通过唯一方向决策门；
- 优化路线通过全部前置门时选择优化路线，否则选择已通过验收的稳定路线；
- 正式结果生成后不得根据结果切换路线；
- 未选择路线的结果只能作为工程诊断或附录，不得混入确认性统计。

稳定路线若进度较快，可在优化路线验证期间启动隔离的预备训练，以利用 A600 空闲时间。预备
训练必须使用与正式实验隔离的预声明 seed 和 `artifacts/stable/predecision/` 产物目录；结果
不得参与方向选择，也不得直接作为最终论文实验。若最终选择稳定路线，必须在决策后按冻结协议
重新执行正式训练与评估。

## 非目标

- 不构建执行期在线 LLM 调度；
- 不声称 LLM 直接分配 AGV、生成路径或输出逐步动作；
- 不声称 MAPPO 已学习完整高层任务分配或自主充电调度；
- 当前 Roadmap 不以 CBS 替换 A*；
- 不同时把两条路线包装成核心正式方法，也不在看到正式结果后选择更有利路线；
- 稳定路线不支持中科院二区保证、未见拓扑泛化或 8-AGV 规模泛化主张。

## 开放问题

无。后续实现细节由各阶段 feature spec 冻结，不得改变本 Mission 的路线边界。
