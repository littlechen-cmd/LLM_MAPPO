# Mission

## 项目名称

LLM-A-MAPPO 多教师蒸馏多智能体路径规划与调度研究

## 论文定位

- 论文语言：英文；
- 现实投稿目标：以中科院二区方法论文为目标，一区仅在创新性与正式证据明显超预期时上探；
- 暂定英文题目：*Multi-Teacher Knowledge Distillation for Multi-Agent
  Reinforcement Learning-Based Path Planning*；
- 仓储 AGV 是验证载体，论文核心贡献必须落在多教师蒸馏与 MARL 多智能体路径规划/局部协同，
  而非特定仓库应用系统或自主高层任务调度。

## 一句话概述

面向动态仓储多 AGV 场景，构建以 MAPPO 为最终动作策略、A* 为路径/运动教师、离线 LLM
为语义教师的多教师蒸馏系统，在执行期保持零在线 LLM 调用。正式核心实验采用三个规模的
持续任务流场景和四组配对方法；不同语义 schema 仍须通过配置与 checkpoint 身份严格隔离。

## 目标用户

- 多智能体强化学习与知识蒸馏研究者；
- 仓储机器人路径规划、运动协同与调度研究者；
- 评审本项目方法、实验与可复现证据的论文评审者。

动态仓储 AGV 是方法验证场景。当前项目交付目标是可复现的研究方法与论文证据，不是可直接
部署到真实仓库的商业调度产品。

## 要解决的问题

项目研究两类异构教师能否向同一 MAPPO 策略提供互补监督：A* 提供可解释的路径与局部运动
先验；离线 LLM 提供经单独批准、版本化的语义监督；MAPPO 通过环境交互、team reward 与
集中式 critic 学习最终运动动作和多智能体局部协同。任务优先级、任务队列和安全充电目标仍由
规则层处理。历史二维与候选三维语义不得混用，本版采用四维时序语义及独立标签身份。

当前正式核心实验合同为 `baseline`、`A* KD`、`LLM KD`、`A* KD + LLM KD` 四组，
分别在 RWARE tiny-3AGV、现有 medium-5AGV 与 50×28 formal-8AGV 场景上训练与评估。
每个场景每组使用相同的八个配对训练 seed 和 200 个固定评估实例；按训练 seed 统计配对
差异。12/16 台 AGV 的同图零微调压力评估与未见拓扑均为后续单独决定的探索性工作，
不混入本轮主比较。具体环境、配置和验证条件以
`specs/2026-09-28-formal-environment-training/` 为准。

## 成功标准

### 共同标准

- 始终保留“A* 路径/运动教师 + 离线 LLM 语义教师 + MAPPO”的多教师技术主线；
- MAPPO 是最终动作策略；规则层继续负责任务队列、合法目标、充电安全目标和硬约束；
- 训练、评估和执行阶段在线 LLM API 调用次数均为 0；
- 正式运行保存本轮已授权的代码、环境、奖励、seed、预算、checkpoint、指标和失败处理
  版本；baseline优化带来的后续修订生成新身份，不静默改历史合同；短测模板为provisional；
- 每项论文主张都能追溯到冻结日志、统计证据或明确限制。

### 核心实验准入条件

- 三场景的静态布局、任务流、充电、观测维度、动作掩码与完整交付循环通过确定性核验；
- 四组方法除教师因子外使用相同的环境、reward、PPO、预算、seed 和评估实例；
- A* 教师只对规则层既定目标提供运动监督，不改写目标、任务优先级或充电意图；
- 离线 LLM 标签定义、有效性和来源通过版本化审查；训练和评估时在线 LLM 调用为 0；
- 三场景预算由研究所有者于 2026-09-30 确定为 tiny/medium/formal 的
  450k/900k/1.8M 累计环境步；短测证据及初版参数由架构师按负责人最新授权确定，真实产物仍须核验；
- 冻结后任何算法失败、安全失败、NaN、死锁或能量死亡均保留为结果，不按结果换 seed。

### 持续任务流证据

三场景使用每完成一单即补一单的固定时长任务流，以交付数、每千步吞吐及安全事件为主指标。
正式图主比较为 8 台 AGV、1,200 步；另由研究所有者按已批准协议运行 5,000 步、10 个
预留实例的耐久评估，检查分段吞吐、补货循环、充电恢复、能量死亡与死锁。有限时长内表现
不得写成无限运行保证。12/16 台同图零微调压力评估须先有充电容量合同和 Actor-only
评估入口，并与 8 台主比较分开报告。

## 正式实验的论文边界

- 三个场景分别报告，比较四种方法；对同一场景的 8 个配对训练 seed 做统计推断；
- 固定拓扑上未见随机实例的鲁棒性与跨拓扑泛化是不同主张；未见拓扑须单独批准后才能评估；
- 12/16 台 AGV 压力结果只有在相同容量及评估协议下才能作为规模外推证据；
- 正式结果生成后不得依据结果改变 seed、预算、指标或方法定义。

## 非目标

- 不构建执行期在线 LLM 调度；
- 不声称 LLM 直接分配 AGV、生成路径或输出逐步动作；
- 不声称 MAPPO 已学习完整高层任务分配或自主充电调度；
- 本轮不以 CBS 替换 A*；
- 不把未见拓扑或 12/16 台压力测试写成已经完成的正式性能门；
- 不凭有限步评估声称无限运行、安全概率为零或跨拓扑泛化。

## 开放问题

各场景预算与初版reward/PPO/教师合同已按负责人授权确定，具体数值和启动步骤见
`docs/handoff/三场景核心实验训练配置.xlsx`。baseline优化引起的变化须版本化修订。
LLM标签与真实表示尚未完成，属于产物依赖；压力测试容量与未见拓扑另行决定。
