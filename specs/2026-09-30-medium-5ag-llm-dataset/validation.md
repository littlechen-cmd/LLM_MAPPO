## 确定性验证

1. 在无网络、无 API 密钥的 CPU 环境中，使用短回合 fixture 检查相同输入产生相同 episode、分区和所选窗口哈希；逐回合压缩文件可用 `allow_pickle=False` 校验、哈希可复算，新增回合不重写已有回合；改变 seed、Actor、环境或配置身份时生成新身份或拒绝 resume。
2. 构造 5 AGV 对齐及故意缺失/重复 AGV、跨回合窗口、相邻终点不足 8 步、非 209D、非有限观测和跨分区重复 fixture；正常样本通过，非法样本均在付费调用前失败。
3. 用模拟 provider 验证 120 试标、6000 主配额、单条一次重试、按保守 token 公式和峰时单价预算预检查、失败日志、断点恢复、请求已发但响应未持久化时暂停、返回模型/fingerprint 漂移暂停，以及密钥不进入清单。验证 6000 条日志读写的运行时间和空间随记录数线性增长。
4. 对 60 条试标执行匿名审阅并按冻结定义记录两级错误；从原始请求日志重算全部质量指标、费用和 Go/No-Go。没有独立人类复核时，receipt 明示审阅者为 Codex，不作人类验证主张。
