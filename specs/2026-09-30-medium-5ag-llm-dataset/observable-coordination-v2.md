2026-10-06 的引用修订保持上述语义合同和校验器：向模型提供从原始可观察视图推导的完整引用组合，明确当前局部同行、过去局部同行及无同行三种情况，供模型选择分数并引用。引用策略及依赖代码哈希写入新配置和身份；旧试标与全部费用保留在独立目录及递归预算链中。

## 语义边界

### 2026-10-06 已批准的一次定向引用修复

所有者明确答复“批准定向修复并继续”。在同一冻结身份下保留已经通过的
776 条主标签和所有原始请求，仅为常规重试耗尽且第四维正分缺少模式对应
原始路径的响应，允许每个语义视图跨 scope 最多追加一次请求。必须先验证
原始分数存在可观察证据且可由完整原始引用支持，再向模型说明正确路径及
观察值；由模型重新返回完整四维 JSON，执行原校验器，禁止改写原标签。
授权绑定批准时的账本前缀、dataset/config/identity 及实现代码哈希。
额外请求由协调器在同批全部任务结束后发送；额外请求自身遇到网络未知结果
不能再次补试，保留全部费用预留。累计预算、HTTP/token 上限、重试率≤10%
及其他质量门不变。授权、实际额外请求和修复提示哈希随交付保存。

- DeepSeek 继续只接收单 AGV 的 8 帧、209D 可观察状态转换的时序视图，不能访问全局状态、等待图、未来路线或身份追踪信息。安全规则、MAPPO 动作策略、A* 静态几何教师保持原职责。
- 新合同 `observable-coordination-four-score-v2` 保留四个传输字段，以维持现有张量和代码入口；历史字段 `deadlock_severity` 在本合同中只表示**可观察的持续阻塞或重复振荡指标**，不得称作已确认或全局死锁。合同版本写入标签、预训练及导出身份，禁止与旧语义混用。
- 第四维正分需要当前活动阶段与活动目标、正电量，以及当前稳定阶段及目标类型片段中的直接证据：至少三次记录为阻塞的 FORWARD 请求且当前仍记录为阻塞；或至少四次 LEFT/RIGHT 转向、至少三次左右交替、目标距离保持不变，且片段没有任何缺少阻塞记录的 FORWARD 请求。`previous_blocked=False` 不能证明移动成功（部分碰撞未计入），上述条件刻意保守，不能表述为真实无运动。阶段或目标类型变化前的证据不计入；片段首帧的 previous action/blocked 属于旧状态转移，必须跳过（窗口首帧同样不计入）。以上为保守候选依据，不证明真实死锁；直线距离变化、普通转弯、远处 AGV、空闲 NOOP 均不能独立支持正分。
- 让行和交互风险正分需要实际局部同行证据，历史局部占用仅可支持弱分。当前 idle/no-goal 的任务紧迫度必须为零。校验拒绝不支持的分数，不改写模型标签。
- 本轮不引入未知掩码，不修改 209D 学生输入，也不从仿真隐藏状态生成可部署教师输入。
- `non_peer_free_degree` 把货架纳入阻断，是局部几何代理而非实际可通行性；空载与载货的通行规则不同。动态场景选择须明确此限制，不能只据该代理断言车辆无法通行。普通进展对照仅表示活动阶段中存在未标阻塞的 FORWARD 请求及可观察目标距离下降，不证明同一目标身份或成功位移。

## 数据与职责

- 原 120 个回合和旧 6000 窗口及全部付费审计均保留。新选样建立独立派生目录，以哈希绑定源回合和旧 dataset，不覆盖旧标签或窗口。
- 先核验现有回合的直接证据覆盖；train 加强持续阻塞、局部空间竞争与瓶颈内同行场景，同时保留普通道路、空窄通道、正常绕障、任务结束等反例。
- validation/test 沿原回合分区分别对候选作固定哈希排序抽样，不按困难类别重加权。保留 4200/900/900、8 帧、回合隔离、同 AGV 终点间隔至少 8 步、全局视图去重；记录自然候选与最终样本的分布差异。
- 困难判据与配额在调用 API 前冻结，只根据可观察状态选择，不根据模型返回分数反复筛选。若现有回合不足，先报告覆盖缺口，再准备有界增补；不能放宽语义以制造正例。
- 本轮 train 预标注配额为 840 个直接阻塞／振荡候选、1260 个非上述候选的局部动态竞争上下文、2100 个固定哈希代表性补充；阻塞与振荡候选优先各 420 个。普通补充须含至少 120 个无局部同行且有可观察目标接近的活动场景，以及至少 120 个无局部同行的受限局部空间场景。试标 120 条采用上述三类各 40 个，按固定哈希及类别轮转排列，使复标、Pro 对照和 60 条审阅覆盖各类。
- 输出同输入的确定性规则教师对照标签，供后续离线预训练消融使用；规则是可复算对照，不作为已验证死锁真值。LLM 的增益由后续训练和多 seed 评估检验，不以两教师一致性直接证明。

## 验证与预算

- 固定正例、反例及边界案例须覆盖持续阻塞、交替振荡、成功前进、普通转向、阶段变化、无电量、空闲、远近同行及瓶颈对照。离线回归通过后，先运行新合同下的 120 条试标、40 条复标及 40 条 Pro 对照，再完成 60 条模型匿名语义审阅。
- 保留已批准质量策略 v2：解析率 ≥0.98、重试率 ≤0.10、禁用内容为零、证据有效率 ≥0.98、每维标准差 ≥0.08、复标 MAE ≤0.15、Pro 对照 MAE ≤0.20、60 条审阅严重错误为零且实质错误 ≤3。边界率只作诊断；最终 train 每维至少 120 条分数 ≥0.25。
- 原官方 API 外发授权与累计 50 美元、1 亿输入 token、500 万输出 token 上限继续有效。新 v7 请求真实超时设置为 180 秒；累计 HTTP 上限为 primary 7000 / repeat 200 / comparison 128，包含历史请求，不能绕过美元和 token 上限。旧未知结果继续保留完整费用预留，不能认定未发送或清零。
- 同一新身份缓存续跑，全部旧版本隔离。试标、固定案例、语义审阅均通过后才全量；最后实际验证预训练加载和版本身份。只交付数据与 owner-run 训练命令，不由代理运行正式长训练。
